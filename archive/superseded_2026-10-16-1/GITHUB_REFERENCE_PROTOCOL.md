This PROCEDURE release changes access/recovery steps only; numerical policy, scoring, selection and log formats are unchanged.

## Required recovery

1. Keep **https://github.com/danisgreat/Sports-Research/tree/main** as the standing repository reference for every task. When a required local repository file is absent, unreadable, truncated, incomplete or inaccessible, consult this repository immediately and retrieve the actual required files/sections before declaring them unavailable. This applies to controls, full prompts, sport/league rules, archive/provenance, logs and model/execution documentation. A failed local read is not a completed search.
2. Use an available authorized GitHub/browser/connector or Git fetch/read route. If a page is truncated or only navigation, retrieve the full file using its file view, raw content or authenticated Git tooling. Do not claim success from a folder listing, title, search snippet, cached summary or link alone. If the repository requires authentication, use only access already available to the task; record actual access failures truthfully.
3. Resolve current main to one full commit SHA for that run, then read the relevant files at that commit, for example `.../blob/<full-SHA>/<path>`. Record the repository URL, exact paths/sections, SHA, access/read time with timezone, local access failure and successful/failed fallback. The `/tree/main` URL is the discovery reference; it is not an immutable snapshot. Preserve [CURRENT_RULES](CURRENT_RULES.md) section 0 authority modes.
4. In PUBLISHED_MAIN_PINNED mode, all controls must come from that single pinned main commit. In LOCAL_WORKING_TREE mode, disclose remote fallback files and compare them with the local HEAD/known working differences before relying on them; do not label an unread local variant as read. If consistent governing controls cannot be established, pause the dependent mutation, or explicitly restart the independent read-only research under one published pinned authority. Never silently mix main revisions with local edits or overwrite local files just to obtain access.
5. GitHub cannot supply an unpublished local mini, unsaved change or private artifact that was never uploaded. Do not substitute a different published original, reconstruct missing bytes, backdate a receipt or claim a local write/readback. Continue independent research and return an honest READ_ONLY_DRAFT / NOT_ISSUED when the dependent original/write gate cannot pass. Discover and use a genuinely matching committed original only with identity/custody verification.
6. If both local access and authorized GitHub routes fail, record actual attempts/errors and the exact unread dependency. Complete all independent work under [RESEARCH_COMPLETION_PROTOCOL](RESEARCH_COMPLETION_PROTOCOL.md). No rule permits fabricated file content, compliance, source evidence or execution.

Reading GitHub code or a receipt is not executing ML/RL. [ML_EXECUTION_PROTOCOL](ML_EXECUTION_PROTOCOL.md) still requires actual run/feedback evidence. This reference rule grants no additional GitHub write/publication permission and does not change any issued original, model probability, ID, grade or format.
