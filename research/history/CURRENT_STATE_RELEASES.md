**Previous release — MDS/P v24.0 / CR-2026.10.22-R2 / SCV-v12 / SEL-v4 / REFMODEL-v1 / LEDGER-v1 / PICKS-v2 / MLSCOPE-v3:** STATISTICAL + FORMAT + PROCEDURE, owner instruction 22 October 2026, implementing the [framework revamp review](../verification/review_2026-10-22_framework_revamp/REPORT.md). A game card now starts from a reference that is frozen before any probability is written (declared per competition in `REFERENCE_CHOICE.csv`; tier A/B/C from `ml reference tier`; the NBA reference is TB-2-MD, an additive attack/defence form that removes the margin-halving of TB-1-MD), builds p_card as the reference plus logged adjustments sized from the effect tables, and prints a linted `PICKS_V2` block (a probability for every supplied contract, a most-likely list, an information list, an abstain flag) instead of the Rank-1 gate, Rank-2 floor and five shadows. The card's own final p is frozen beside the reference (MLSCOPE-v3); every adjustment, reference, baseline, line-implied and frozen-model probability is scored in the append-only adjustment ledger (`research/adjustment_ledger/`), with the adjustment value λ estimated from settled rows and adjustments held at half size until λ rests on 40 adjusted rows. Width floors come from residual SDs (`COMPETITION_PARAMETERS`); benchmarks (no-vig close, Squiggle, ClubElo, Tennis Abstract Elo) are entered by hand after settlement as probabilities only. Simulators (baseball, tennis, hockey, cricket, props) exist under `ml/sim/` and stay NOT_VALIDATED until they pass structural checks; exact calculation is used wherever it suffices. Statistical changes now wait for a season boundary or a new lane (STATFREEZE-v1) and governance text is stated once in [CORE](../../CORE.md) with pointers elsewhere (GOV-v2). NBA lane built: two-lineage backfill of three seasons (3,693 verified finals), a release gate, **NBA-CYCLE-1** frozen (experimental, 0 prospective events) and `ml league-day freeze|settle` for a daily league lane; its first freeze (22 October 2026, before tip-off) holds two NBA games, LOCAL-LEAGUE-NBA-20261022-G0001 and G0002, to be settled with `league-day settle`. Not done, by design: soccer, AFL, NRL, NFL, cricket, tennis and rugby have no stored history or release, so they stay tier B/C and abstain readily; the simulators and the props model have no validation data; the measured NBA back-to-back effect is in-sample significant but not out-of-sample, so it runs at half size. No ID, grade, forecast or issued record changed. [Implementation](../verification/framework_change_2026-10-22-2/IMPLEMENTATION.md).
