**Purpose:** reproducible legacy diagnostic view only. It is not a verified decision ledger, H0 training set, preferred-choice cohort or performance dataset. The historical source files remain unchanged; this directory is regenerated by `research/settled_rows_2026-09-25/extract_settled_rows.py` using exact normalized contract joins and conflict quarantine.

These counts are parser coverage, **not** unique decisions and not verified outcomes. Exact contract text normalization only reconciles display variants; it cannot establish that event or contract terms are truly identical.

## Files

| File | Meaning |
|---|---|
| `settled_rows.csv` | Retained rows with sport, rank, contract fingerprint, p/q, baseline, preferred flag if found, horizon, blank identities/timestamps where unrecoverable, `outcome_verified=false`, `performance_eligible=false`, exclusion reason and source locations. |
| `conflicts.csv` | One row per card/rank conflict group with source locations and variants. Quarantined rows do not flow into calibration diagnostics. |
| `unattributed_rows.csv` | Raw table occurrences that cannot be safely assigned to one card; retained for manual review. |
| `coverage.txt` | Compact reproducible count summary emitted by the extractor. |

## Use and rebuild

```powershell
python research/settled_rows_2026-09-25/extract_settled_rows.py
python tools/calibration_report.py
python tools/semantic_validation.py research/settled_rows_2026-09-28/prospective_records.json
python tools/evidence_status.py
```

The calibration report's default is `LEGACY_MIXED_DIAGNOSTIC`. It is not a current skill estimate. `p >= 0.5` cannot identify the analyst's preferred side; explicit frozen preference is required. Push-capable outcomes need the complete W/P/L(/V) vector, never a silently dropped P/V. For prospective scoring use [prospective_records.json](../prospective_records.json), its [schema](../prospective_record.schema.json) and [record contract](../RECORD_SCHEMA.md); none of the legacy CSV rows can enter that gate through inference.
