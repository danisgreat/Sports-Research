[Owner scope/proposal](CHANGE_PROPOSAL.md), [standing retention rule](../../../RESEARCH_RETENTION_PROTOCOL.md), [canonical import](CANONICAL_IMPORT_REPORT.md), [verification](VERIFICATION_REPORT.md).

## Implemented behavior

| Area | Change |
|---|---|
| Record and ID | Missing ML/RL model/adapter/runtime/module/data/baseline/calibration or receipt never by itself blocks a researched card or verified canonical retention |
| Numerical honesty | RESEARCH_ONLY_NO_MODEL, absent model p_card, supported analyst_p separately NOT_PRIMARY; no fake execution artifact or model win/gate |
| Actual execution | Attempt supported actual models when accessible, retaining genuine runs/failures; no receipt needed to document honest no-run research |
| Manifest/C21 | One honest disposition per new card; empty nonexistent execution paths and explicit no-model reason accepted. Actual artifact paths/hashes still verify |
| Settlement/S16 | Every retained event can be settled under its original terms; unknown fields stay unresolved, regardless of model availability |
| Future labels | ml.research_learning retains reviewed terminal labels, originals, source/time/hash/revision/feature status as immutable RESEARCH_TRAINING_CANDIDATE bundles without requiring a forecast model |
| Expert feedback | primary.feedback_losses explicitly rejects research target/candidate artifacts. Actual frozen grids remain required for historical expert losses |
| Import | Prompt4 permits authorized retention-only import before settlement; preserve contiguous IDs, source custody, original policy/timing/unknowns |
| Scope | All eleven game workflows, eight lifecycle prompts, common/index/rules/method/templates/scoring/contribution/ML/GitHub source instructions aligned |

New formats mini-log-9 / mini-settlement-8; older cards/minis retain original format and bytes. Future-learning fields are separate from model-performance metrics. SCV-v11 adds coverage for research-only records and future labels, without changing Brier/log-loss/T2 formulas or retroactively recoding old results.
