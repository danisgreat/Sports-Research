 삼성 한화 꺾고 승승승승...KBO 최초 팀 5600홈런 폭발 
 
 
 
 또 이겼다. 

 삼성 라이온즈가 한화 이글스를 꺾고 4연승을 질주했다. 삼성은 30일 대구삼성라이온즈파크에서 열린 한화와의 홈경기에서 6-2로 승리했다. 선발 아리엘 후라도는 시즌 9승째를 거뒀다. 최형우의 홈런으로 KBO 최초 팀 5600홈런을 달성했다.  

 삼성은 김지찬(중견수)-김성윤(우익수)-구자욱(좌익수)-르윈 디아즈(1루수)-최형우(지명타자)-강민호(포수)-김영웅(3루수)-이재현(유격수)-류지혁(2루수)으로 선발 라인업을 구성했다. 1군 엔트리에 변화를 줬다. 내복사근 부상을 당한 우완 김백산을 엔트리에서 말소하고 좌완 베테랑 백정현을 1군에 콜업했다.  

 이에 맞서는 한화는 외국인 투수 오웬 화이트를 선발 투수로 내세웠고 중견수 최인호-우익수 요나단 페라자-좌익수 문현빈-지명타자 강백호-3루수 노시환-포수 허인서-1루수 김태연-2루수 정은원-유격수 심우준으로 타순을 짰다.  

 삼성은 1회 2사 주자 없는 가운데 구자욱이 한화 선발 화이트를 상대로 베이스를 맞고 굴절되는 행운의 안타를 만들어냈다. 구자욱은 지체 없이 2루까지 내달렸다. 슬라이딩 과정에 왼쪽 햄스트링 통증을 느껴 대주자 박승규와 교체됐다. 곧이어 디아즈의 적시타로 1점을 먼저 얻었다.  

 1점 차 앞선 2회 1사 1루서 이재현이 화이트에게서 좌중월 투런 아치를 빼앗으며 3-0으로 달아났다. 이 홈런으로 이재현은 개인 한 시즌 최다 홈런 타이 기록을 작성했다. 그러자 한화는 3회 심우준이 삼성 선발 후라도를 상대로 좌월 2점 홈런을 때려내며 1점 차로 압박했다.  

 이후 한화는 최인호와 페라자의 연속 안타, 강백호의 볼넷으로 2사 만루 기회를 잡았다. 노시환이 헛스윙 삼진으로 물러나며 뒤집기 실패. 삼성은 1점 차 앞선 5회 2사 1,3루서 최형우가 우중월 3점 아치를 작렬했다. 6-2.  

 삼성 선발 후라도는 7이닝 7피안타(1피홈런) 1볼넷 4탈삼진 2실점으로 잘 던졌다. 최형우는 5회 3점 홈런을 터뜨렸고 디아즈는 멀티히트 포함 1타점 1득점으로 힘을 보탰다.  

 반면 한화 선발로 나선 화이트는 5이닝 8피안타(2피홈런) 1볼넷 3탈삼진 6실점으로 고개를 떨궜다.

 // 선수 검색
 function getPlayerSearch() {
 if ($("#txtTopPlayerWord").val() == "") {
 alert("선수명은 필수 입니다.");
 $("#txtTopPlayerWord").focus();
 return false;
 } else {
 //var searchWord = encodeURI($("#txtTopPlayerWord").val());

 //if (searchWord != "") {
 // location.href = "/Player/Search.aspx?searchWord=" + searchWord;
 //}
 var request = $.ajax({
 type: "post"
 , url: "/ws/Controls.asmx/GetSearchPlayer"
 , dataType: "json"
 , data: {
 name: $("#txtTopPlayerWord").val()
 }
 , error: ajaxFailed
 , async: true
 });

 request.done(function (data) {
 if (data.code == "100") {
 var container = $(".search-result");
 container.children().remove();

 container.hide();

 if (data.now.length > 0 || data.retire.length > 0) {
 // 2017-05-22 yeeun, 홍지희 사원 요청, 결과가 1명일 경우 바로 페이지 연결
 if (data.now.length + data.retire.length == 1) {
 var link = "";

 if (data.now.length == 1) {
 link = data.now[0]["P_LINK"];
 } else {
 link = data.retire[0]["P_LINK"];
 }

 location.href = link;
 } else {
 if (data.now.length > 0) {
 container.append($(" 등록 선수 "));

 var div = $(" ");
 div.children().remove();

 setPlayerDiv(data.now, div, true);

 container.append(div);
 }

 if (data.retire.length > 0) {
 container.append($(" 역대 선수 "));

 var div = $(" ");
 div.children().remove();

 setPlayerDiv(data.retire, div, false);

 container.append(div);
 }

 //container.append($(String.format(" '{0}' 검색결과 모두 보기 ", $("#txtTopPlayerWord").val())));
 container.append($(" '" + $("#txtTopPlayerWord").val() + "' 검색결과 모두 보기 "));
 container.show();
 }
 } else {
 container.append($(" 검색 결과가 없습니다. "));
 container.show();
 }
 }
 });
 }
 }

 // 선수 검색 div 
 function setPlayerDiv(list, div, isActive) {
 $.each(list, function (index, player) {
 var aLink = $(" ");
 aLink.attr("href", player["P_LINK"]);

 var dl = $(" ");
 var dt = $(" ");
 var backNo = "";

 if (isActive) {
 //backNo = String.format("No.{0}", player["BACK_NO"]);
 backNo = "No." + player["BACK_NO"];
 }

 //dt.text(String.format("{0} {1}", player["P_NM"], backNo));
 dt.text(player["P_NM"] + " " + backNo);
 dl.append(dt);

 var dd = $(" ");
 //dd.text(String.format("{0} {1}({2})", player["T_NM"], player["POS_NO"], player["P_TYPE"]));
 dd.text(player["T_NM"] + " " + player["POS_NO"] + "(" + player["P_TYPE"] + ")");
 dl.append(dd);

 var ddImg = $(String.format(" ", "//6ptotvmi5753.edge.naverncp.com/KBO_IMAGE/KBOHome"));
 dl.append(ddImg);

 aLink.append(dl);
 div.append(aLink);
 });
 }
