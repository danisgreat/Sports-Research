# Verified historical backfill

Owner results and ESPN finals matched by date, participants, exact scheduled UTC instant and score. Native provider IDs distinguish doubleheaders. Regulation derives from owner innings or NHL OT/SO rule; the independent source corroborates finals only. `final_at` is the current observed-final upper bound, not an actual final whistle time. `known_at` is current retrieval, so these rows cannot enter historical pregame replays. Player lineups are not reconstructed from final box scores. Raw HTTP bodies remain in the external cache named in HTTP_RECEIPTS.csv; the committed fact projections and hashes are the ingest evidence. Every owner candidate has a reconciliation disposition. This is a bounded backfill, not closure of all historical cards.
